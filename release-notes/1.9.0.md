- **Выход «Авто»** — самый быстрый из рабочих туннелей. Выбирается для программы, правила, маршрута по умолчанию или как резерв; в интерфейсе видно, какой туннель он выбрал сейчас.
- **Замер скорости** в «Серверах»: тестовый файл скачивается через каждый выход, видна реальная скорость в МБ/с.
- **«Не отвечает»:** если VPN подключён, но не пропускает трафик, Splitroute замечает это за минуту, переводит его программы в резерв и присылает уведомление; когда VPN оживёт — возвращает.
- **Совместимость с VPN на Xray/sing-box** (например, ZoogVPN в режиме Xray): они занимают ту же сеть 198.18.0.0/16, что и Splitroute, и весь трафик уходил мимо раздельного туннеля. Теперь Splitroute сам выбирает свободный адрес.
- После обновления Splitroute один раз попросит обновить системный компонент (пароль администратора).

## Установка

Если у вас уже стоит Splitroute — он предложит обновление сам (или «Настройки → Обновления → Проверить»).

Новая установка: откройте `Splitroute-1.9.0.dmg` и перетащите Splitroute в «Программы». При первом запуске macOS заблокирует приложение без Developer ID: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**, или `xattr -dr com.apple.quarantine /Applications/Splitroute.app`.

New install: open `Splitroute-1.9.0.dmg` and drag Splitroute to Applications. macOS blocks apps without a Developer ID on first launch: **System Settings → Privacy & Security → “Open Anyway”**, or run `xattr -dr com.apple.quarantine /Applications/Splitroute.app`.
