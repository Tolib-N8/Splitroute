- **Splitroute работает в фоне.** Крестик теперь только закрывает окно: приложение остаётся в строке меню и продолжает следить за сетью — переключать на резервный VPN, пересобирать маршруты при смене Wi‑Fi, включать сценарии и присылать уведомления. Иконка в Dock видна, пока открыто окно. Полностью выйти — «Выйти» в мини-окне или ⌘Q.
- **Мини-окно в строке меню** вместо простого меню: переключатель маршрутизации, живая схема потоков, скорость, сценарий, состояние VPN (и куда ушёл трафик отключённого), переключатель VPN / Напрямую / Блок для приложений, которые сейчас в сети, и подсказки о блокировках.
- Анимация потоков останавливается, когда её окно скрыто, свёрнуто или закрыто, — в фоне Splitroute почти не нагружает процессор.

## Установка

Если у вас уже стоит Splitroute — он предложит обновление сам (или «Настройки → Обновления → Проверить»).

Новая установка: откройте `Splitroute-1.7.0.dmg` и перетащите Splitroute в «Программы». При первом запуске macOS заблокирует приложение без Developer ID: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**, или `xattr -dr com.apple.quarantine /Applications/Splitroute.app`.

New install: open `Splitroute-1.7.0.dmg` and drag Splitroute to Applications. macOS blocks apps without a Developer ID on first launch: **System Settings → Privacy & Security → “Open Anyway”**, or run `xattr -dr com.apple.quarantine /Applications/Splitroute.app`.
