- **Codex CLI** распознаётся как программа из терминала: «Добавить приложение → Программы из терминала → Codex CLI». Правило ставится на папку версий и переживает обновления Codex (standalone, Homebrew и npm).
- Маршрут самого Splitroute (через него скачиваются обновления и базы) теперь следует за приложением, если его перенесли, например из «Загрузок» в «Программы».

## Установка

Если у вас уже стоит Splitroute — он предложит обновление сам (или «Настройки → Обновления → Проверить»).

Новая установка: откройте `Splitroute-1.0.2.dmg` и перетащите Splitroute в «Программы». При первом запуске macOS заблокирует приложение без Developer ID: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**, или `xattr -dr com.apple.quarantine /Applications/Splitroute.app`.
