- **Приветствие при запуске:** логотип появляется и рисует свой знак, уезжает влево, а справа из частиц собирается название. Клик — пропустить; при «Уменьшении движения» в macOS не показывается.
- **Живой логотип:** пока маршрутизация включена, по ветвям знака бегут точки трафика — чем больше скорость, тем быстрее. По клику знак перерисовывается. Знак теперь везде тот же, что на иконке приложения.
- **Иконки отвечают на клик:** пункты меню и кнопки подпрыгивают, «обновить» и шестерёнка проворачиваются, пауза на «Маршрутах» плавно меняется на воспроизведение.
- Все анимации останавливаются, когда окно скрыто: в фоне Splitroute почти не нагружает процессор.

## Установка

Если у вас уже стоит Splitroute — он предложит обновление сам (или «Настройки → Обновления → Проверить»).

Новая установка: откройте `Splitroute-1.8.0.dmg` и перетащите Splitroute в «Программы». При первом запуске macOS заблокирует приложение без Developer ID: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**, или `xattr -dr com.apple.quarantine /Applications/Splitroute.app`.

New install: open `Splitroute-1.8.0.dmg` and drag Splitroute to Applications. macOS blocks apps without a Developer ID on first launch: **System Settings → Privacy & Security → “Open Anyway”**, or run `xattr -dr com.apple.quarantine /Applications/Splitroute.app`.
