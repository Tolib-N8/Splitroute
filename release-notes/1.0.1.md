Исправления плавности на экране «Маршруты».

- Частицы больше не перескакивают: их положение привязано к потоку, а не к его номеру в списке.
- Тонкий поток приложения больше не прыгает вверх-вниз, когда у приложения несколько выходов.
- Чтение сетевых настроек ушло с главного потока — пропали подвисания раз в 3 секунды.
- Без ограничения 60 кадров в секунду: ровнее на дисплеях 120 Гц.

## Установка

Если у вас уже стоит 1.0.0 — Splitroute предложит обновление сам (или «Настройки → Обновления → Проверить»).

Новая установка: откройте `Splitroute-1.0.1.dmg` и перетащите Splitroute в «Программы». При первом запуске macOS заблокирует приложение без Developer ID: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**, или `xattr -dr com.apple.quarantine /Applications/Splitroute.app`.
