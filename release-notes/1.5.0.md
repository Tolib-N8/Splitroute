## Установка

Если у вас уже стоит Splitroute — он предложит обновление сам (или «Настройки → Обновления → Проверить»).

Новая установка: откройте `Splitroute-1.5.0.dmg` и перетащите Splitroute в «Программы». При первом запуске macOS заблокирует приложение без Developer ID: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**, или `xattr -dr com.apple.quarantine /Applications/Splitroute.app`.

New install: open `Splitroute-1.5.0.dmg` and drag Splitroute to Applications. macOS blocks apps without a Developer ID on first launch: **System Settings → Privacy & Security → “Open Anyway”**, or run `xattr -dr com.apple.quarantine /Applications/Splitroute.app`.
