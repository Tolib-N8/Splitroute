Первый релиз Splitroute — раздельный туннель по приложениям для macOS.

## Что умеет

- **Каждое приложение — своим путём:** через VPN-приложение (ZoogVPN, AIRLINK…), через свой конфиг (VLESS/Reality, Shadowsocks, Trojan, Hysteria2, WireGuard, OpenVPN, подписки), напрямую или в блок — одновременно, без переключений.
- **Программы из терминала:** например, Claude Code — правило переживает обновления.
- **Правила по доменам, IP и портам** и готовые наборы: «Китайские сервисы → напрямую», «Заблокированное в Китае → VPN», блок рекламы.
- **DNS без подмены:** пока ядро работает, имена резолвятся через VPN; китайские и локальные — напрямую.
- **Kill switch:** если VPN отключился, его приложения блокируются, а не уходят в интернет напрямую.
- **Журнал** соединений с причиной маршрута, **потоки трафика**, значок в строке меню, горячие клавиши ⌥⌘V / ⌥⌘J / ⌥⌘R.
- **Автообновления** из GitHub Releases с проверкой подписи Ed25519.

## Установка

1. Откройте `Splitroute-1.0.0.dmg` и перетащите Splitroute в «Программы».
2. Приложение подписано без Apple Developer ID, поэтому при первом запуске macOS его заблокирует. Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»** рядом с сообщением о Splitroute. Или в Терминале:
   ```
   xattr -dr com.apple.quarantine /Applications/Splitroute.app
   ```
3. Пройдите приветствие: установите системный компонент (один раз понадобится пароль администратора) и выберите, какие приложения пускать через VPN.

Требования: macOS 15 или новее, Apple Silicon.
